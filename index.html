Privacy

No analytics, cookies, or network calls for your events after the app shell is loaded.

Backup

Back up regularly. Everything lives only in this browser. If you clear site data, cookies, or the browser cache, all calendar events are permanently deleted and cannot be recovered without an export.

Use the Backup tab to share or save events as JSON (optional encryption) or iCalendar (.ics).

A file with your events, countdowns and settings. Stored only where you save or share it.

Last backup: never

Encrypted JSON uses AES-256-GCM with a key from PBKDF2-HMAC-SHA512 (210,000 iterations). Your password is never stored; if you lose it, the file cannot be opened.

iCalendar is always plaintext so other calendar apps can open it — not a secure stash.

This app never holds a folder handle; the copy only exists where you put it.
